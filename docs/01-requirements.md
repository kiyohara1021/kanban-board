# 01. 要件・画面

## 機能一覧

### MVP（まずここまで作る）

| 対象   | 機能                                                                   |
| ------ | ---------------------------------------------------------------------- |
| ボード | 一覧表示、作成、名前変更、削除                                         |
| カラム | 追加、名前変更、削除、ドラッグで並び替え                               |
| カード | 追加、タイトル・説明の編集、削除、ドラッグで並び替え、別カラムへの移動 |

### MVP の後に追加した機能

| 対象   | 機能                                                                                             |
| ------ | ------------------------------------------------------------------------------------------------ |
| ラベル | ボードごとに作る色付きのタグ。作成、削除、カードへの付け外し。カードの一覧とカード詳細に表示する |
| 期限日 | カードごとの期限日（任意）。設定、変更、消去。期限を過ぎたカードを目立たせる                     |

#### ラベル

- ラベルは名前（必須）と色（決まった6色から選ぶ）を持つ。色だけでは見分けにくい人や、読み上げで使う人にも区別できるよう、名前を必ず付ける
- ラベルの作成・削除・付け外しは、カード詳細のモーダルで行う。付け外しはタイトルや説明と同じく「保存」で確定する
- ラベルを削除すると、付けていたすべてのカードから外れる
- 名前や色の変更はまだ扱わない（削除して作り直す）

#### 期限日

- 期限日は時刻を持たない「日付だけ」にする。かんばんのカードは「何日までに」で管理することが多く、時刻まで入れると入力の手間が増えるため
- 期限日の設定・変更・消去は、カード詳細のモーダルで行う。タイトルや説明と同じく「保存」で確定する。カードを作るときには設定しない（作ったあとにカード詳細で設定する）
- カードの一覧では、期限日を「11月5日」のように表示する。今年でない日付は「2027年1月5日」のように年も付ける
- 期限日が今日より前のカードを「期限切れ」として強調する。期限日が今日のカードは、その日のうちはまだ間に合うので期限切れにしない
- 「今日」は、画面を見ている人のパソコンの日付で決める
- 期限切れの強調は、色だけに頼らない。赤い色に加えて「期限切れ」の文字とアイコンを出し、読み上げでも分かるようにする
- かんばんには「完了」を表すカラムの決まりがないので、どのカラムにあるカードでも、期限を過ぎていれば期限切れとして表示する。完了したカードは期限日を消せば強調が消える

### MVP の後に追加する候補

- カードの検索・絞り込み
- ログインと複数ユーザー対応
- リアルタイム同期（WebSocket）

## 画面

| パス                             | 画面                   | 内容                                                                       |
| -------------------------------- | ---------------------- | -------------------------------------------------------------------------- |
| `/`                              | ボード一覧             | ボードの一覧と新規作成フォーム                                             |
| `/boards/:boardId`               | ボード                 | カラムとカードの表示、追加、ドラッグ操作                                   |
| `/boards/:boardId/cards/:cardId` | カード詳細（モーダル） | ボード画面の上にモーダルを重ねて、タイトル・説明・ラベル・期限日を編集する |

カード詳細を開いているかどうかを URL で表すと、リロードしても開いたままになり、URL を共有することもできる。

## MVP では扱わないこと

- 認証（誰でも全ボードを操作できる）
- 同時編集の衝突対策（最後に保存したものが残る）
